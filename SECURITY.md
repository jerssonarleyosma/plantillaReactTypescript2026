# Política de seguridad

## Versiones compatibles

La seguridad se mantiene en la versión más reciente de la plantilla.

| Versión | Soporte |
| ------- | ------- |
| 1.x     | Sí      |
| < 1.0   | No      |

## Reportar una vulnerabilidad

No publiques vulnerabilidades en un issue, discusión, pull request ni otro canal público.

Envía el reporte de forma privada a `jerssonarleyosma@gmail.com` con el asunto
`[Seguridad] plantillaReactTypescript2026`.

Incluye, cuando sea posible:

- Una descripción clara de la vulnerabilidad.
- Los pasos mínimos para reproducirla.
- Las versiones o configuraciones afectadas.
- El impacto potencial.
- Capturas, logs o una prueba de concepto que no contenga datos sensibles.
- Una posible solución, si la conoces.
- Un medio de contacto para solicitar información adicional.

No incluyas contraseñas, tokens, datos personales ni secretos reales en el reporte.

## Proceso de respuesta

Se intentará confirmar la recepción del reporte, reproducir el problema y evaluar su impacto.
Durante la investigación se podrá solicitar información adicional.

Si se confirma la vulnerabilidad, se preparará una corrección y se coordinará su divulgación.
El reporte puede cerrarse sin cambios cuando no sea reproducible, esté fuera del alcance del
proyecto o no represente un riesgo de seguridad; en ese caso se explicará el motivo cuando sea
posible.

## Divulgación responsable

Mientras el problema se investiga:

- No lo explotes fuera de un entorno controlado.
- No accedas, modifiques ni elimines datos de terceros.
- No interrumpas servicios.
- No publiques detalles antes de que exista una corrección o un acuerdo de divulgación.

El objetivo es proteger a quienes usan la plantilla y reconocer de manera responsable a quien
ayude a mejorar su seguridad.
